# AGENTS.md

Guidance for AI coding agents working in this repo.

## What this is

Techniqually's marketing site: a single static `index.html` page, deployed to
GitHub Pages at `www.techniqually.com` via `.github/workflows/deploy.yml` on
push to `master`. No framework, no CMS, no backend. Styling is Tailwind CSS
compiled locally with the Tailwind CLI (`npm run build` / `npm run watch`) —
see `README.md` for the full dev/build/deploy loop.

## Brand & positioning — do not drift from these without the user's say-so

- Techniqually is positioned as a **software & AI solutions studio**
  (custom software, applied AI/automation, data & analytics, systems
  integration, technical consulting) — not a "digital marketing agency."
  That was the pre-2026 framing and was deliberately dropped.
- **Never add fabricated social proof.** No invented client names,
  testimonials, project case studies, or stats (e.g. "50+ projects,"
  "98% satisfaction"). If asked to add social proof, either use real
  content the user supplies or keep the site capability/process-led.
  This was a deliberate correction in the 2026 revamp — the previous
  version of this site had fake testimonials and a fake portfolio.
- Visual identity: dark-mode-first, single accent color **"Signal Amber"
  `#FF8A1E`** (hover `#E67300`), background `#0B0B0D`, surface `#17181C`,
  text `#F5F5F4` / muted `#9A9A9E`. Deliberately avoids the generic
  "AI startup" look (no purple/blue gradients, no neural-net/glow hero
  art). See `tailwind.config.js` for the full token scale.
- On any accent-colored button, use near-black text (`text-bg`), not
  white — white-on-`#FF8A1E` fails WCAG AA contrast.
- Logo is a hand-authored inline SVG ("node-T" mark: a T shape built from
  4 circles + 2 lines, `currentColor`-themed) — not a raster image. It
  appears inline in `index.html` (nav + footer) and as
  `assets/images/favicon.svg`. If it ever needs to change, regenerate
  `favicon.png` / `apple-touch-icon.png` from the SVG (a Node-based
  rasterizer like `sharp` works locally; no ImageMagick/rsvg-convert is
  assumed to be available in the sandbox).

## Working in this repo

- Real contact info (address, phone, email, social handles) lives in the
  Contact section and footer of `index.html` — keep these in sync if one
  changes; don't alter them without the user confirming the change is real.
- `assets/css/main.css` is a build artifact — it's git-ignored and
  regenerated by `npm run build`. Never hand-edit it; edit
  `src/input.css` / `tailwind.config.js` instead.
- `package-lock.json` is intentionally tracked (not ignored) so CI's
  `npm ci` is reproducible.
- The GitHub Actions artifact upload does **not** respect `.gitignore`
  — the workflow explicitly `rm -rf node_modules` before
  `upload-pages-artifact` to avoid bundling it into the published site.
  Keep that step if the workflow is edited.
- Repo Settings → Pages → Source must stay set to "GitHub Actions" (not
  "Deploy from a branch") for the workflow to actually serve the build.
